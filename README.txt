JATINDER & JESSICA — FIND YOUR TABLE
GOLD HALO V2

This version contains:
- Gold halo only around the selected table
- No burgundy circle or outline
- No bouncing or continuous pulsing
- One gentle fade-in
- Cache-busted CSS and JavaScript filenames
- PNG logo and PNG venue layout

IMPORTANT GITHUB UPLOAD STEPS
1. Delete the old website files from the root of the GitHub repository.
2. Extract this ZIP.
3. Upload every individual file from this folder directly into the repository root.
4. Commit the changes.
5. Wait around one minute for GitHub Pages to redeploy.
6. Open the live site and press Ctrl + Shift + R on a computer.
   On a phone, close the tab fully and reopen the link.

The new files are called style-v2.css and script-v2.js. These names prevent the
browser from reusing the previous burgundy-circle styling from its cache.
